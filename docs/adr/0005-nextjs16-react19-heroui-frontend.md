# 0005: Frontends Next.js 16 com React 19 e Design System HeroUI

As aplicações de interface (`swiftpay-web` para o painel de lojistas e `swiftpay-web-checkout` para o checkout de compradores) foram construídas com Next.js 16 App Router, React 19 e Tailwind CSS 4.
Padronizamos o uso de componentes HeroUI obrigatórios com `variant="secondary"` e o padrão composto para Switches, proibindo elementos HTML de formulário não-controlados para assegurar consistência visual estrita e acessibilidade.
